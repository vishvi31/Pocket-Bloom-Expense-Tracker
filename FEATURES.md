# Pocket Bloom - Features

## Dashboard

- Net Cash Flow overview
- Inflow vs Outflow split
- Recent activity feed
- Smart Insights guilt-free spending panel

## Add Transaction

- Choose income or expense type
- Enter amount in Indian Rupees
- Add category and notes
- Mark as fixed commitment

## Transaction History

Full searchable log of all transactions.

## Analytics

- Spending by category chart
- Income vs expense over time
- Monthly trends view

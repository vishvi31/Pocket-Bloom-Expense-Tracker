# Developer Notes - Pocket Bloom

Author: Vishvi
Date: 2026-06-01

---

## Why I Built Pocket Bloom

Most budgeting apps feel restrictive and guilt-inducing.
Pocket Bloom flips that: it calculates what you can freely
spend AFTER fixed responsibilities are covered.
The result is guilt-free, intentional spending.

---

## Technical Decisions

| Decision | Reason |
|---|---|
| Lovable as builder | Fastest path from idea to live app |
| React + TypeScript | Type safety and component reusability |
| Tailwind CSS | Rapid, consistent UI styling |
| Cyan theme | Fresh, calm, growth-oriented feeling |

---

## Smart Insights Logic

The core formula powering the app:

Step 1: Add all income sources
Step 2: Subtract fixed commitments (rent, EMI, family support)
Step 3: Remaining = guilt-free spending money

This shifts the mindset from restriction to clarity.

## What I Learned

- Translating a real personal pain point into a product
- Designing around user psychology, not just features
- Shipping fast with AI-powered tools like Lovable
- The value of a clear, single core feature

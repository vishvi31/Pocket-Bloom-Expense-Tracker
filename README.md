## About

Pocket Bloom is a personal finance web app that helps you understand
where your money goes and grow your savings intentionally.
Built around guilt-free spending: once fixed commitments are covered,
what is left is yours to enjoy freely.

## Features

| Feature | Description |
|---|---|
| Dashboard | Net cash flow, inflow, outflow at a glance |
| Smart Insights | Guilt-free spending after fixed commitments |
| Add Transactions | Log income and expenses in seconds |
| Transaction History | Full log of all past transactions |
| Analytics | Visual breakdown of spending patterns |
| Fixed Commitments | Track rent, EMIs, family support |
